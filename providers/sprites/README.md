# Fly Sprites provider adapter

Provider-specific implementation and exact receipts stay at [theseus-sprites](https://github.com/TeaShaman-cyber/theseus-sprites). Begin with its current reviewed [RULES.md](https://github.com/TeaShaman-cyber/theseus-sprites/blob/main/RULES.md), selected `sprites-core-router` skill, and official current Fly/Sprites mechanics.

Use this provider after **observed exe.dev mismatch/blocking** or when a task specifically targets a Sprite. Avoid relying on stale VM identifiers or treating REST gateway OAuth as native git/gh login.

Portable lessons to extract once accepted: bounded exec/transport, guest-side postcondition readback, runtime-local tool catalog, deterministic QA, Drive artifact integrity. Preserve source and private operational data as separate domains; no mass transfer of Sprite credentials or disk.

This adapter is a pointer, **not** an announcement that the old repo has been deprecated or source authority transferred.
